# AWS Architecture Icons

The SVG files in this folder are AWS Architecture Icons, taken unmodified from the official
asset package that AWS publishes at https://aws.amazon.com/architecture/icons/
(release `Icon-package_07312026`).

One file per lesson topic, named after that topic's slug, so `ServiceIcon` can resolve it from
the slug alone without the API needing to know anything about assets.

AWS provides these icons for use in architecture diagrams, documentation, presentations and
training material. They remain AWS trademarks: do not alter them, and do not use them in a way
that suggests AWS produced or endorsed this application. Re-download the package from the link
above to refresh them; AWS revises it roughly quarterly.

Where a topic is a concept rather than a single service (the shared responsibility model, the
migration strategies), the file is an AWS category or architecture-group icon instead.
